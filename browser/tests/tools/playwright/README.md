# Playwright — TypeScript (Playwright)

The runnable sample for **[Playwright](https://endtoendtester.com/tools/playwright)**.

[![browser.yml](https://github.com/8exgh/endtoendtester-samples/actions/workflows/browser.yml/badge.svg?branch=main)](https://github.com/8exgh/endtoendtester-samples/actions/workflows/browser.yml?query=branch%3Amain)

Runs on every push. The badge above is live; click it for the last result.

## Running it

```bash
cd browser && npm ci && npx playwright install --with-deps chromium && npx playwright test
```
